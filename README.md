# ml-big-data

Веб-приложение для загрузки CSV-файлов, выбора целевой переменной и автоматического обучения модели машинного обучения с интерактивной визуализацией результатов.

## Возможности
- **Загрузка данных:** Drag & Drop или выбор файла, валидация формата `.csv`.
- **Предпросмотр:** Табличное отображение первых 5 строк загруженного датасета.
- **Выбор целевой переменной:** Гибкий выбор целевого столбца для регрессионного анализа.
- **Фоновое обучение:** Асинхронный запуск модели (Random Forest).
- **Визуализация:**
  - Статистика признаков (среднее, стандартное отклонение)
  - Метрики модели (R², MSE)
  - Важность признаков 
  - Scatter plot (фактические vs предсказанные значения)
  - Гистограмма распределения остатков
- **Адаптивный интерфейс:** Минималистичный дизайн, корректное масштабирование на мобильных и десктопах.

## Как запустить

### 1. Клонирование репозитория 

```bash
$ git clone https://github.com/olmaximova/ml-big-data.git
$ cd ml-big-data
```

### 2. Запуск приложения
```bash
docker compose up --build
```

- Приложение будет доступно по адресу: `http://127.0.0.1:8000/`

- Swagger будет доступен по адресу: `http://127.0.0.1:8000/docs`

## API Reference

| Метод | Путь | Описание |
|-------|------|----------|
| `POST` | `/api/upload/file` | Загрузка CSV, возврат `upload_id`, статистики и превью |
| `POST` | `/api/training/start/{upload_id}` | Запуск фонового обучения модели |
| `GET`  | `/api/training/status/{job_id}` | Получение статуса задачи и метрик |
| `GET`  | `/api/visualization/chart-data/{upload_id}` | Данные для графика статистики |
| `GET`  | `/api/visualization/model-metrics/{job_id}` | Метрики модели |
| `GET`  | `/api/visualization/model-charts/{job_id}` | Данные для графиков важности, scatter и остатков |

## Руководство пользователя
1. **Загрузка:** Перетащите `.csv` в область загрузки или нажмите «Выбрать файл».
2. **Обучение:** Выберите целевую переменную из выпадающего списка и нажмите «Запустить обучение».
3. **Результаты:** После завершения обучения секции с метриками и графиками появятся без перезагрузки страницы.
